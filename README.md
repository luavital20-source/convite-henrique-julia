# Convite de Casamento — Henrique & Julia

Convite digital (página única) para o casamento de Henrique e Julia — 03/02/2027, às 16h, em Salvador - BA.

- `index.html` — o convite completo (abertura com monograma, foto do casal, versículo, cerimônia e recepção com mapas, contagem regressiva, manual do convidado, dress code, lista de presentes e confirmação de presença). As informações ficam no bloco `CONFIG` no fim do arquivo.
- `midia/` — monograma, fotos do casal e textura de papel.

Música: definida em `CONFIG.musicaYoutube` (código do vídeo do YouTube). Ela começa quando o convidado toca em "toque para abrir"; os navegadores não permitem som antes de um toque.

Para publicar, ative o GitHub Pages em **Settings → Pages** apontando para a branch com estes arquivos (pasta raiz).
